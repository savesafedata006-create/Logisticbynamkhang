1. ภาพรวมระบบ

🏠 หน้าหลัก — Portal กลาง: สร้างงาน, ดูรายการ, เชื่อมทุก module
🗄️ Datacenter — ฐานข้อมูลกลาง: Buyers, Shipments, Products, Routes, Exchange Rates
📋 ทีมเอกสาร — แบบฟอร์มเอกสาร Export ครบชุด: Invoice, PC, CO Form E, Sales Contract, Lab
📦 Container Hub — บริหารตู้ Container ครบวงจร
🚛 Fleet Hub — บริหารกองรถ, จัดรถ AI, ค่าเที่ยว, น้ำมัน

3. Admin / ผู้จัดการ

Login: admin / admin123 หรือ manager / mgr123
  • Dashboard — ดูสถิติทั้งหมด, Shipment status, Exchange rates
  • Datacenter → เพิ่ม/แก้ไข Buyers, Products, Routes, Exchange Rates
  • ทีมเอกสาร → สร้าง Invoice, Sales Contract, ติดตามเอกสาร
  • Container Hub → ดู Dashboard, อนุมัติแจ้งซ่อม
  • Fleet Hub → ดู KPI กองรถ, ค่าเที่ยว, อนุมัติซ่อม

4. CS / ประสานงาน

Login: cs / cs123
  • สร้างงานใหม่ → กด "สร้างงานด่วน" กรอก Container, ลูกค้า, ปลายทาง
  • ติดตาม Shipment → ดู status ใน รายการงาน
  • Container Hub → ดู ID Card ตู้, EIR Gate-In/Out

5. ฝ่ายเอกสาร

Login: doc / doc123
  • เปิด ทีมเอกสาร → เลือก Tab เอกสารที่ต้องการ
  • กรอกข้อมูล → กด Preview → พิมพ์เอกสาร
  • บันทึกเลขเอกสารใน Datacenter → ทะเบียนเอกสาร
  • เอกสารที่ต้องเตรียม: Invoice/PL → Sales Contract → Lab Test → PC → CO Form E

6. ช่าง / คนขับ

🔧 ช่าง (tech / tech123) → Container Hub: ดูงานซ่อมที่ได้รับมอบหมาย, อัปเดตสถานะ
🚚 คนขับ (driver / driver123) → แจ้งซ่อมรถใน Fleet Hub
ระดับความเร่งด่วน: 🟢 ต่ำ (ยังขับได้) · 🟡 กลาง (3 วัน) · 🔴 สูง (หยุดทำงาน)

7. Tips & Tricks

⚡ Auto-Complete — พิมพ์ 2-3 ตัว ระบบแนะนำลูกค้า/ล้ง/เบอร์ตู้ทันที
🤖 AI แนะนำรถ (Fleet Hub) — วิเคราะห์ประเภทตู้ + OTP + Safety Score คนขับ
⚠️ แจ้งเตือนเอกสารรถ — Fleet Hub แสดงเตือนเมื่อภาษี/ประกัน จะหมดใน 30 วัน
🔑 Session ข้ามหน้า — Login ครั้งเดียว กดไปทุก module ได้เลย ไม่ต้อง Login ซ้ำ
